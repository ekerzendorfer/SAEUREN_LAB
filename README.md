# SÄUREN_LAB v0.3.1

Kleine Brückenanpassung zu Phase 9:

- Die bisherige allgemeine Aufgabe „Unbekannte Essigsäure“ im TITRATIONSTOOL wird nicht mehr verwendet.
- Stattdessen öffnet das SÄUREN_LAB direkt die neue Aufgabe **TITR_A10**.
- TITR_A10 verwendet bereits 10,0 mL Probe und 0,100 mol/L NaOH.
- Im großen Tool wird ausschließlich das unbekannte NaOH-Volumen am Äquivalenzpunkt bestimmt.
- Die komplette quantitative Auswertung bleibt im SÄUREN_LAB (Phase 10).
